# Objetivo 1: Puertos y Servicios Esenciales

| Puerto | Protocolo(s) | Servicio | Función Principal |
| :--- | :--- | :--- | :--- |
| **20** | TCP | FTP (Datos) | Transferencia de archivos (canal de datos) |
| **21** | TCP | FTP (Control) | Autenticación y comandos de control FTP |
| **22** | TCP | SSH / SFTP / SCP | Administración remota segura y transferencia cifrada |
| **23** | TCP | Telnet | Acceso remoto por terminal (en texto plano) |
| **25** | TCP | SMTP | Envío y enrutamiento de correo electrónico |
| **53** | TCP / UDP | DNS | Resolución de nombres de dominio a direcciones IP |
| **80** | TCP | HTTP | Tráfico web sin cifrar |
| **110** | TCP | POP3 | Descarga y recepción de correo electrónico |
| **443** | TCP / UDP | HTTPS | Tráfico web cifrado mediante TLS/SSL |
| **3306** | TCP | MySQL / MariaDB | Conexión a bases de datos relacionales |
