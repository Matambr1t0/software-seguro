# Objetivo 3: Reconocimiento Cotidiano (Subdominios en uso)



1. **Twitter / X – Portal para Desarrolladores**
   * **URL completa:** `https://developer.x.com` (antes `https://developer.twitter.com`)
   * **Subdominio:** `developer` (sobre el dominio raíz `x.com` / `twitter.com`)
   * **Función:** Documentación oficial, gestión de credenciales y acceso a las APIs de la plataforma.

2. **Twitter / X – Centro de Ayuda**
   * **URL completa:** `https://help.x.com` (antes `https://help.twitter.com`)
   * **Subdominio:** `help` (sobre el dominio raíz `x.com` / `twitter.com`)
   * **Función:** Soporte técnico, políticas de uso y guías de seguridad para usuarios.

3. **Instagram – Servicio de Ayuda y Soporte**
   * **URL completa:** `https://help.instagram.com`
   * **Subdominio:** `help` (sobre el dominio raíz `instagram.com`)
   * **Función:** Centro de asistencia, recuperación de cuentas y reportes de privacidad.

4. **Instagram – Plataforma Informativa y Corporativa**
   * **URL completa:** `https://about.instagram.com`
   * **Subdominio:** `about` (sobre el dominio raíz `instagram.com`)
   * **Función:** Blog oficial de novedades, funciones de seguridad y recursos para creadores.

5. **Infobae – Portal Principal de Noticias**
   * **URL completa:** `https://www.infobae.com`
   * **Subdominio:** `www` (sobre el dominio raíz `infobae.com`)
   * **Función:** Distribución de contenido periodístico y portal web principal del medio (en arquitectura DNS, `www` actúa como el subdominio estándar destinado a servir el tráfico web principal frente al dominio raíz o *apex domain*).
